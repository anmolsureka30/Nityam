# Staircase Projectile Collision Method
`staircase_projectile_collision_method`


## Taught in shruti:52f8e6f7ad_77f6cb3e @2:41
A technique used to find which step a horizontally projected object hits by modeling the steps as coordinates on a grid. For a staircase with step width b and step height h, the edge of the n-th step is defined by the coordinates (nb, -nh). Substituting these coordinates into the horizontal projectile trajectory equation, y = -gx^2 / (2u^2), yields the step number n as n = 2hu^2 / (gb^2).
