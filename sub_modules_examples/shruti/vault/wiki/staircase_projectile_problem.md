## Taught in shruti:cecb347d78_77f6cb3e @6:58
An analysis of a projectile thrown horizontally with speed u from the top of a staircase where each step has width b and height h. By defining the coordinates of the edge of the n-th step as (nb, -nh) and substituting them into the horizontal projectile trajectory equation y = -gx^2 / (2u^2), the step number on which the ball lands is derived as n = 2h(u^2) / (g * b^2).

## Taught in shruti:a070d0331a_77f6cb3e @10:06
An analytical model used to determine which step of a staircase a horizontally projected object will land on, where each step has a width b and height h. By setting the projection point as the origin, the coordinates of the edge of the n-th step are defined as (nb, -nh). These coordinates are substituted directly into the horizontal trajectory equation y = -g*x^2 / (2*u^2) to yield -n*h = -g*(n*b)^2 / (2*u^2), which simplifies to solve for the integer step index n = 2*h*u^2 / (g*b^2).
